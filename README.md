
# Проектный менеджмент — Система учёта обслуживания автомобиля

Учебный командный проект по дисциплине «Проектный менеджмент» (ВГУ, ФКН).

Цель проекта — выбрать и спланировать разработку информационной системы с использованием методов проектного менеджмента.

По результатам первой фазы выбрана концепция **«Система учёта обслуживания автомобиля»**.

## Фаза 1 — Выбор концепции

### Рассмотренные альтернативы

- **A1** — Система записи на приём к врачу.
- **A2** — Система учёта вещей на хранении.
- **A3** — Система учёта обслуживания автомобиля.
- **A4** — Система аренды инструментов между пользователями.

### Критерии выбора

- **К1** — Сложность реализации (минимизация).
- **К2** — Практическая полезность (максимизация).
- **К3** — Потенциал развития (максимизация).
- **К4** — Независимость от внешних систем (максимизация).

### Методы оценки

Для анализа альтернатив использованы:

1. Коллективный нечёткий TOPSIS.
2. Коллективный метод анализа иерархий (МАИ Саати).
3. Экспертные оценки четырёх участников команды.
4. Сопоставление итоговых рейтингов.

### Выбранная концепция

Для дальнейшей работы выбрана **A3 — «Система учёта обслуживания автомобиля»**.

Концепция заняла первое место по МАИ и разделила второе место по TOPSIS.

Основные преимущества:
- Практическая полезность для автовладельцев.
- Возможность реализации без обязательных внешних интеграций.
- Достаточный функциональный объём для дальнейших фаз проекта.
- Возможность последующего расширения системы.
