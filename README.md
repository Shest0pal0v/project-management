# Проектный менеджмент — Система учёта обслуживания автомобиля

Учебный командный проект по дисциплине **«Проектный менеджмент»** Воронежского государственного университета (ВГУ).

**Выбранная концепция:** система учёта технического обслуживания и ремонта автомобиля. Проект ориентирован на владельцев автомобилей и предполагает ведение истории обслуживания, учёт расходов и планирование будущих сервисных работ.

**Статус Фазы 1: завершена.** Выполнены расчёты нечёткого коллективного TOPSIS и чёткого коллективного МАИ, сопоставлены рейтинги альтернатив и выбрана концепция для дальнейшей разработки.

## Фаза 1 — Выбор концепции проекта

### Цель

Сравнить несколько идей программного продукта и обоснованно выбрать одну концепцию для дальнейшей работы. Для независимого анализа применяются **нечёткий коллективный TOPSIS** и **чёткий коллективный метод анализа иерархий (МАИ)**.

### Рассмотренные концепции

| Код | Концепция | Назначение |
|---|---|---|
| **А1** | Запись на приём к врачу | Поиск специалиста и управление записями |
| **А2** | Учёт вещей на хранении | Каталогизация предметов и мест хранения |
| **А3** | Учёт обслуживания автомобиля | История обслуживания, расходы и планирование ТО |
| **А4** | Аренда инструментов между пользователями | Поиск инструментов и оформление заявок на аренду |

### Критерии выбора

| Код | Критерий | Направление |
|---|---|---|
| **К1** | Сложность разработки проекта | **MIN** — ниже лучше |
| **К2** | Практическая полезность | **MAX** — выше лучше |
| **К3** | Потенциал развития проекта | **MAX** — выше лучше |
| **К4** | Независимость от внешних систем | **MAX** — выше лучше |

### Методика оценивания

**Нечёткий коллективный TOPSIS.** Для оценивания используются словесные экспертные оценки, представляемые треугольными нечёткими числами `(L; M; U)`. В текущей модели коллективная нижняя граница определяется минимумом индивидуальных нижних границ, средняя — средним арифметическим центральных значений, верхняя — максимумом верхних границ. Затем рассчитываются нормализованные и взвешенные оценки, идеальное и антиидеальное решения, расстояния `D⁺` и `D⁻` и коэффициент близости `CC`.

**Чёткий коллективный МАИ.** Каждый эксперт выполняет попарные сравнения критериев и альтернатив по шкале Саати. Индивидуальные матрицы объединяются геометрическим средним; определяются локальные и глобальные приоритеты. Согласованность оценивается показателем `CR`, для которого используется порог **0,1**.

### Итоговый выбор

Для дальнейшей работы **выбрана концепция А3 — «Система учёта обслуживания автомобиля»**.

Результаты методов различаются: TOPSIS отдаёт первое место записи к врачу, а МАИ — учёту автомобиля. Однако А3 занимает первое место по МАИ и разделяет второе место по TOPSIS. Дополнительные аргументы в её пользу — понятная предметная область, возможность реализовать полезную базовую версию без обязательных внешних интеграций и потенциал дальнейшего развития.

## Концепция MVP

Система предназначена для владельцев автомобилей. Для дальнейшей разработки определены основные функциональные возможности:

- регистрация и авторизация пользователей;
- добавление и редактирование автомобилей;
- ведение истории технического обслуживания и ремонта;
- учёт расходов на обслуживание;
- фиксация пробега;
- планирование предстоящих сервисных работ;
- просмотр сводных данных и расходов.

Предварительная функциональность может быть разложена на **10–15 пользовательских сценариев (Use Cases)**. Их детальная проработка относится к последующим фазам, а не к Фазе 1.
